## Product (two features only)

1. **Self-standing** — hinged kickstand deploys so the shovel stands upright alone (no bending to pick it up).
2. **Self-cleaning** — handle-sleeve wiper scrapes the blade clean in one stroke; spring + magnetic return locks it rigid.

Built for job sites, farms, municipal crews, truck stops — real dirt, not a showroom toy.
